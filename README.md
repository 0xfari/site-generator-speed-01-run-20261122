A faster drop-in for makefun-site 1.0.0: it builds the same static sites, byte for byte, in less CPU time. `solve.js` re-implements the makefun-site spec (front matter, template dialect, Markdown subset, slug rule, build report) as one dependency-free module, with the hot paths rewritten — batched HTML escaping, a fused lex-and-render Markdown pass, index-based front-matter parsing, memoised slugs, and scope reuse in template loops. `main.ts` is the driver: it reads `/input/cases.json`, answers each case with `run()`, and writes `/output/answers.json`.

## Run it

```sh
node main.ts
```
